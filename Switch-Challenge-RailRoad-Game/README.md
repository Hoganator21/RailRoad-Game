# Switch Challenge — Seaboard A-Line Railroad Simulator

An interactive American railroad and locomotive cab simulator set along the **Seaboard A-Line corridor from Richmond Acca Yard, VA to Rocky Mount, NC**.

## Features
- **Dual Crew Roles:** Switch seamlessly between **Engineer** (reverser, 8-notch throttle, independent & automatic air brakes, horn) and **Conductor** (switch throws, yard manifests, Wye routing).
- **Acca Yard Wye & Corridor:** Start at Richmond Acca Yard with a working Wye junction branching toward **Bellwood / Rocky Mount (A-Line South)** or the **Clifton Forge Sub**.
- **Positive Train Control (PTC) & Alerter:** Real-time speed limit enforcement, penalty brake applications, and alerter acknowledgement (`Spacebar`).

## Quick Start
Open `index.html` directly in any modern browser, or enable **GitHub Pages** in your repository settings (`Settings -> Pages -> Branch: main / root`) to play live online.
